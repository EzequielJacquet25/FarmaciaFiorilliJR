# Farmacia Fiorilli JR

Sitio institucional y catálogo de preparados magistrales.

Producción: https://farmacia-fiorilli-jr.vercel.app/

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```

## Contenido editable

- Catálogo: `src/data/products.js`
- Información institucional, contacto, horarios y redes: `src/data/site.js`
- Procedimiento para optimizar imágenes y videos: `docs/asset-optimization.md`
